오늘 계산기 10종

자주 찾는 생활 계산기를 한곳에 모았어요. 숫자를 넣으면 버튼 없이 바로 결과가 나와요.

％ 퍼센트 계산기

숫자를 넣는 즉시 결과가 바뀌어요. 위에서 계산 방식을 고르세요.

📅 날짜 계산기

기본값은 오늘(한국 시간)이에요. 날짜를 바꾸면 바로 다시 계산돼요.

⏳ D-day 계산기

시험·여행·기념일까지 며칠 남았는지 확인하세요. 기본 목표일은 올해 크리스마스예요.

🏠 평수 계산기

아파트 공고의 ㎡를 평으로, 평을 ㎡로 바꿔 보세요.

🎂 만 나이 계산기

기준일은 오늘(한국 시간)이에요. 다른 날 기준으로도 바꿀 수 있어요.

💰 시급 계산기

기본값은 2026년 최저시급이에요. 세전 금액이고 4대 보험·세금은 빼지 않았어요.

🧾 부가세 계산기

견적서·영수증 금액을 넣어 보세요.

🏷️ 할인율 계산기

쇼핑할 때 쿠폰을 겹쳐 쓰면 얼마가 되는지 바로 확인하세요.

📏 단위 변환기

분류를 고르고 값을 넣으면 다른 단위 값도 아래에 한꺼번에 보여 줘요.

🏦 이자 계산기

은행 상품 설명서의 연이율과 기간을 넣어 보세요. 우대금리는 더해서 넣으면 돼요.

자주 묻는 질문

무료인가요?

네. 설치·가입 없이 무료로 써요. 입력한 숫자는 서버에 저장하지 않아요.

계산 결과를 믿어도 되나요?

공식과 시험값으로 확인했지만 참고용이에요. 세금·급여처럼 중요한 금액은 기관·회사 기준을 따르세요.

결과를 다른 사람에게 보낼 수 있나요?

결과 공유 버튼을 누르면 입력값이 담긴 링크가 만들어져요. 공유는 선택이에요.
